# Contributing to PuneSahayak

Thank you for helping make civic reporting more accessible.

## Before opening a change

1. Read `PRD.md` and the relevant document in `docs/`.
2. Keep the core flow focused: Describe → Analyze → Review.
3. Do not commit `.env`, API keys, private datasets, or user complaint exports.
4. Add or update a small test when behavior changes.
5. Keep AI output explainable and editable.

## Pull requests

Include:

- What user problem the change solves.
- Screenshots for UI changes.
- Commands run and their results.
- Any model, privacy, or security impact.

## Good first contributions

- Add Marathi and Hinglish test fixtures.
- Improve category descriptions.
- Add accessible labels and keyboard navigation.
- Improve report export formatting.
- Add schema-validation tests.
